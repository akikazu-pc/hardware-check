# Microsoft Store screenshots

Screenshots are captured from the `DistributionChannel=Store` build. They must not show PawnIO, elevation prompts,
other applications, or development tools.

Current Simplified Chinese desktop set:

1. `zh-CN/01-live-monitoring.png` — live CPU, GPU, memory, disk, network, fan and test controls.
2. `zh-CN/04-hardware-inventory.png` — complete local hardware and Windows inventory.

The Store requires at least one desktop screenshot and accepts up to ten. Add screenshots only after visually checking
the saved PNG itself; a successful capture command is not sufficient evidence.
