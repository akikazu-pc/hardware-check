### 驱动卸载残留（v0.1.0 缺陷，v0.1.1 修复）

v0.1.0 退出后，重启仍留下 `PawnIO` 服务和驱动包。复现确认：官方安装程序的 `-uninstall -silent` 每次都只删除文件和注册表项并停止驱动，服务和驱动包都留下，和驱动是否运行无关。v0.1.1 改为由工具用 `pnputil /delete-driver` 和 `sc delete` 删除并核对。主程序退出前占用驱动，服务只能标记为待删除，所以由子进程在主程序退出后执行。

| 场景（管理员权限，开发机，UAC 不弹窗） | 结果 |
| --- | --- |
| 运行前没有驱动，连续两轮 | 读到 CPU 57 °C；退出后服务、驱动包、文件、注册表项全部清空 |
| 已正常安装（模拟其他软件） | 退出后原样保留 |
| 只有残留的服务和驱动包 | 退出后只卸载本次安装的部分，残留保持原样，不主动清理 |
